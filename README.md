WORLD ATLAS — ONE DAY, FIVE REGIONS: a 1024×1024 picture of Tuesday 24 November 2026. A numbered world map sits above five region panels (Middle East, Europe, Asia, Americas, Africa · World) carrying 19 verified stories of the day, plus a BY THE NUMBERS strip and the day's markets. The image is drawn at build time with PIL (see gen.py) and shipped as entry.png; main.ts only copies it to the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
